# Методологический ассистент

**https://thinkred.ru/assistant/** — каркас реферата, курсовой и дипломной по методике
В. С. Безруковой («Как написать реферат, курсовую, диплом», 2004) с методологией
ортодоксального марксизма-ленинизма. По теме строит полный аппарат исследования
(актуальность, противоречие, проблема, объект, предмет, цель, задачи, гипотеза, методы,
этапы, план глав, шаблоны введения и заключения, титульный лист, список литературы),
а через языковую модель разворачивает разделы в редактируемые черновики.

Клиент работает **без сборки и зависимостей** — vanilla JS; ключ модели живёт на сервере,
посетителям он не нужен. Развёртывание — по конвенциям
[caos-platform](https://github.com/thethinkred-ai/caos-platform): CI (тесты → gitleaks)
→ деплой на VPS через Docker.

## Возможности

- **Каркас офлайн** — детерминированный движок без сети; одна и та же тема всегда даёт
  одинаковый результат, разные темы звучат по-разному.
- **Исследовательская логика, а не готовый текст** — «Выявить противоречие» из материала
  (заказ/теория/практика → разрыв → сильное/слабое звено) → **проверка аппарата** (связи
  актуальность↔противоречие↔проблема↔цель↔предмет↔гипотеза↔задачи↔методы, ✅/⚠️/❌) →
  гипотеза-конструктор («Если X, то Y, потому что M, при условиях A и B») → **реестр
  утверждений** (CLM-…) → **источники** (SRC-…) с **конспектами по гл. 4** (понятия, положения,
  тезисы, факты, гипотезы автора, выводы, цитаты, связь с задачами и параграфами) → текст с
  ссылками на ID. Научный линтер и **самоэкспертиза по гл. 10** (критерии качества по типу
  работы), **Research completeness** по выполненным элементам.
- **Новизна — прогноз → результат** (по принципу книги): «Предполагаемая новизна» с полями
  что нового / на каком основании / с чем сверять / что считать подтверждением; после
  исследования — фактический итог и сопоставление с прогнозом. Движок не генерирует
  деклараций «впервые…».
- **Режимы LLM** (доказательная база прежде текста): Explore — карта темы; Verify —
  проверка отдельного утверждения; Compare — матрица подходов; Critic — критика черновика
  по таксономии из 9 ошибок; марксистская категориальная экспертиза.
- **Дисциплинарные профили** (педагогика/экономика/философия/история) со своими методами
  и типами доказательств; неизвестная дисциплина получает общий профиль, а не педагогику.
  Тип исследования (обзор/теоретическое/эмпирическое/…) отделён от формата работы.
- **Развёртывание через модель (без ключа у посетителя)** — ретраи, отмена, дозапуск упавших
  секций, редактируемые секции черновика.
- **Экспорт** — .md, Word-совместимый .doc с титульным листом, автономный .html, печать/PDF;
  в экспорт входит реестр утверждений и источников.
- **Интеграция с [OpenResearch](https://github.com/alphaXiv/OpenResearch)** — research-бриф
  с обязательным разделом реестра CLM/SRC для исследовательских агентов.
- **Защита API-бюджета** — rate-limit по IP (мин/час), дневной лимит, whitelist моделей,
  таймауты апстрима, логи.

## Структура репозитория

```
frontend/            — статический SPA: index.html + UMD-модули (движок, промпты+режимы, LLM, экспорт, модель утверждений, бриф, UI)
backend/             — LLM-прокси: ключ и лимиты на сервере (Node, без зависимостей)
tests/               — 293 проверки: движок, модель утверждений, LLM-слой и режимы, экспорт, прокси, research-бриф
infrastructure/nginx — конфиги: site.conf (контейнер) и edge-фрагменты для thinkred.ru
scripts/             — локальный предпросмотр
.github/workflows    — Assistant CI (тесты → линт → gitleaks) и Deploy (SSH на VPS)
```

## Быстрый старт

Локально (только каркас, без модели — просто открыть):

```bash
cd frontend && python3 -m http.server 8080   # или открыть index.html напрямую
```

Полный стек в Docker (как на продакшене):

```bash
git clone https://github.com/thethinkred-ai/ml-research-assistant.git
cd ml-research-assistant
cp .env.example .env    # вписать UPSTREAM_KEY и ALLOW_MODELS
docker compose up -d --build
# страница: http://127.0.0.1:8088/ , API: http://127.0.0.1:8787/api
```

## Деплой

Схема как у caos-platform: **CI → (зелёный?) → Deploy**.

1. На VPS (однократно): `git clone` в `/opt/ml-assistant`, `cp .env.example .env`, заполнить;
   подключить фрагменты из `infrastructure/nginx/edge-thinkred.conf` в server-блок thinkred.ru
   (страница `/assistant/`, модель `/api/`), `docker compose up -d --build`.
2. В secrets репозитория: `VPS_HOST`, `VPS_SSH_KEY` (пользователь root).
3. Дальше пуш в `main` деплоится сам; красные сборки не деплоятся никогда.

## Переменные окружения (backend)

См. `.env.example`: `UPSTREAM_KEY`, `UPSTREAM_URL`, `ALLOW_MODELS`, `ALLOW_ORIGIN`,
`RATE_PER_MIN`, `RATE_PER_HOUR`, `DAILY_LIMIT`, `HOST`, `PORT`.

## Тесты

```bash
npm test    # 293 проверки: движок (124) · модель (57) · LLM+режимы (42) · экспорт (32) · прокси (15) · бриф (23)
npm run lint
```

## Методология и честное использование

Идеологическая рамка (диалектический и исторический материализм, противоречие как источник
развития, практика как критерий истины) задана намеренно и честно помечается в генерируемом
тексте — это заявленная методология, а не «нейтральная наука». Сервис — учебно-методический
помощник: модель может ошибаться в фактах и ссылках (места помечены `[источник]`), автор
работы проверяет, дорабатывает и отвечает за итог.
