# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/), версии — SemVer.

## [1.2.0] — 2026-10-01
### Добавлено
- Структура репозитория и CI/CD по конвенциям [caos-platform](https://github.com/thethinkred-ai/caos-platform):
  `frontend/` + `backend/` + `tests/` + `infrastructure/nginx/`, Docker Compose, workflows
  «Assistant CI» (тесты → линт → gitleaks) и «Deploy» (SSH на VPS после зелёного CI).
- Прокси-режим по умолчанию: клиент работает без API-ключа (Base URL `/api`, ключ и лимиты — на сервере).
### Изменено
- Тесты переехали в `tests/` (191 проверка), пути обновлены.

## [1.1.0] — 2026-09-27
### Добавлено
- Развёртывание через модель: ретраи с backoff, таймаут/отмена, дозапуск упавших секций, параллельность.
- Вкладки «Каркас»/«Черновик», редактирование секций и исходника, единый экспорт (.md/.doc/.html/печать).
- Титульный лист с редактируемыми полями; проверка темы на широту/перегруженность; шаблон Заключения;
  словарь начинающего исследователя (18 терминов).
- Пресеты дисциплин, вариативность формулировок (детерминированная по хэшу темы), свои источники,
  ссылки на подбор литературы (КиберЛенинка/Scholar/eLibrary).
- Интеграция с OpenResearch (alphaXiv): экспорт research-брифа для агентов с командами orx.
- Прокси: rate-limit по IP, дневной лимит, whitelist моделей, таймауты, 413, логи.
- Исправлен латентный баг UMD-обёртки («global is not defined» в браузере).

## [1.0.0] — 2026-09-27
### Добавлено
- Первоначальный выпуск: офлайн-каркас по методике В. С. Безруковой (актуальность, противоречие,
  проблема, объект, предмет, цель, задачи, гипотеза, методы, этапы, план, введение, литература),
  экспорт .md/.html, развёртывание через LLM с личным ключом, серверный прокси.
