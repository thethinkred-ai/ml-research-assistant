# План разработки веб-сервиса «Методологический ассистент» (по методичке В. С. Безруковой, позиция ортодоксального марксизма-ленинизма)

Дата: 2026-09-27

## 1. Что это за сервис

Веб-сервис, который по заданной теме и параметрам строит **полный методологический каркас** учебной/научной работы (реферат, курсовая, дипломная) строго по методике из книги «Как написать реферат, курсовую, диплом», а затем разворачивает разделы в связные черновики с позиций **ортодоксального марксизма-ленинизма** (диалектический и исторический материализм как методология, практика как критерий истины, единство теории и практики, формационный/классовый анализ, законы диалектики).

Пользователь вводит тему → получает готовый документ-каркас (актуальность, проблема, объект, предмет, цель, задачи, гипотеза, методы, этапы, план глав, шаблон введения, стартовый список литературы) и, при подключении LLM, развёрнутые тексты разделов. Экспорт в Markdown / HTML / PDF.

### Позиционирование и честное использование
Сервис — **помощник по написанию и обучению методологии**, а не «генератор для сдачи чужой работы». Это соответствует духу самой книги (она предостерегает от «слепого переписывания» и плагиата). В интерфейс встроена заметка: сгенерированное — учебный черновик/каркас, который автор дорабатывает и за который отвечает. Это снижает репутационные и антиплагиат-риски публичного размещения.

## 2. Ключевые технические решения

- **Двухслойная генерация.** Слой «каркас» — чистая логика (JS), работает офлайн, бесплатно, детерминированно, без внешних вызовов. Слой «проза» — вызов LLM (OpenAI-совместимый `/chat/completions`) с ключом владельца сайта. Без ключа сервис всё равно полезен (отдаёт каркас + шаблоны).
- **Стек для простоты размещения:** статический SPA (HTML + CSS + vanilla JS), никаких сборок и зависимостей на клиенте. Хостится где угодно (обычный хостинг, GitHub Pages, nginx). LLM-ключ — либо в браузере пользователя (localStorage), либо через маленький прокси-сервер на бэкенде (рекомендуется для публичного сайта, чтобы не светить ключ и не ловить CORS).
- **Приватность и стоимость:** прокси на бэкенде (Node/Python) — опциональный шаг; на шаге 1–2 всё статично.

## 3. Архитектура

```
ml-research-assistant/
  index.html        — UI: форма, вывод, кнопки экспорта
  styles.css        — оформление (можно инлайн)
  engine.js         — методический движок (чистые функции, тестируется в Node)
  llm.js            — обёртка вызова LLM (chat/completions) + фолбэк
  prompts.js        — системные промпты МЛ-методологии и по разделам
  export.js         — сборка Markdown/HTML, скачивание, вызов печати в PDF
  server/           — (опц.) прокси для LLM-ключа + rate-limit
  PLAN.md           — этот файл
```

## 4. Модель данных (вход)

```
{
  topic: string,                 // тема
  kind: "referat"|"kursovaya"|"diplom",
  field: string,                 // дисциплина/область (педагогика, экономика, философия…)
  hasEmpirical: boolean,         // нужна ли эмпирическая часть (эксперимент)
  applied: boolean,              // прикладной характер
  volumePages: number,           // ориентировочный объём
  extraKeywords: string          // доп. акценты
}
```

## 5. Что генерирует движок (по главам книги)

По гл. 2 «Проектирование исследования» и гл. 3 «Структура»:
1. **Актуальность темы** — с МЛ-фреймингом (противоречие, общественная потребность, практика как критерий).
2. **Проблема** — из установленного противоречия.
3. **Объект** и **Предмет** исследования.
4. **Цель** и **3–5 Задач** (задачи не повторяют цель, не шире её — по книге).
5. **Гипотеза** (если есть эмпирика) — «если … то … при условии …».
6. **Методы** — теоретические (анализ, синтез, абстрагирование, идеализация, формализация, исторический и логическое, восхождение от абстрактного к конкретному) + эмпирические (наблюдение, эксперимент, анкетирование, беседа, тестирование, статистика).
7. **Этапы** исследования.
8. **Научная новизна** и **практическая значимость**.
9. **План/структура** — Введение, 2–3 главы с параграфами (для диплома — теоретическая + эмпирическая + методическая), Заключение, Список литературы, Приложения.
10. **Шаблон введения** — связный текст-каркас с подстановкой темы.
11. **Стартовый список литературы** — классики марксизма-ленинизма (Маркс, Энгельс, Ленин), методичка Безруковой + плейсхолдеры под тему.

## 6. Методология марксизма-ленинизма (встроена в промпты и шаблоны)

- Диалектический материализм как общий метод: законы единства и борьбы противоположностей, перехода количественных изменений в качественные, отрицания отрицания; категории сущность/явление, причина/следствие, содержание/форма, возможность/действительность.
- Исторический материализм: базис и надстройка, общественное бытие определяет сознание, формационный подход, классовый анализ, единство теории и практики, практика как критерий истины.
- Требование: анализ темы через противоречия и материальные условия, а не через идеалистические «вечные» категории.

## 7. Поэтапная сборка и тестирование

- **Шаг 1 — движок каркаса (`engine.js`).** Чистые функции, без DOM. Тест: Node-скрипт прогоняет 3–4 темы/типа и проверяет, что все обязательные блоки непустые и задачи≠цель. ✅ тестируется.
- **Шаг 2 — UI (`index.html`).** Форма → вызов движка → рендер документа + кнопки «Скачать .md / .html», «Копировать». Тест: загрузка в headless-браузере, скриншот, проверка, что вывод появляется.
- **Шаг 3 — LLM-развёртывание (`llm.js`, `prompts.js`).** Кнопка «Развернуть разделы через модель»; при отсутствии ключа — вежливый фолбэк (возвращает каркас). Тест: мок-ответ модели + проверка сборки текста.
- **Шаг 4 — экспорт и деплой.** PDF через печать браузера; README с инструкцией размещения и (опц.) прокси для ключа; заметка о честном использовании.

## 8. Риски и ограничения

- Качество прозы зависит от подключённой модели и ключа; офлайн-режим даёт каркас, а не «книгу на 60 страниц».
- Публичный доступ → нужен лимит запросов и защита ключа (прокси), иначе расходы на вас.
- Идеологическая рамка задаётся как заявленная методология; сервис честно помечает её как марксистско-ленинскую, а не «нейтральную науку».
- Правовой/этический: позиционируется как учебный помощник; ответственность за сдачу — на авторе.

## 9. Критерий готовности MVP

Пользователь открывает страницу на своём хостинге, вводит тему и тип работы, получает полный методический каркас (все блоки по книге) с МЛ-фреймингом и может скачать его в .md/.html; при введённом ключе — развёрнутые черновики разделов.
