# Как участвовать

Проекту рады: фронтенд (vanilla JS без сборки), Node-бэкенд, тесты, методические тексты, дизайн.

1. Сделайте fork и ветку: `git checkout -b feature/что-делаете`.
2. Проверьте локально: `npm test` (191 проверка) и `npm run lint`.
3. Коммиты — по-человечески, одним языком (русский ок).
4. Push и откройте Pull Request. CI (тесты → линт → gitleaks) должен быть зелёным —
   красные сборки не деплоятся.

## Соглашения

- Клиент — без сборки и зависимостей: vanilla JS, UMD-модули, изменения сразу в `frontend/`.
- Новая логика — с тестами в `tests/` (шаблон: счётчик `ok` + `process.exit(fail?1:0)`).
- Секреты — только в `.env` (в `.gitignore`), никогда в коде; gitleaks сканирует каждый PR.
- Структура и CI/CD — по образцу [caos-platform](https://github.com/thethinkred-ai/caos-platform).
