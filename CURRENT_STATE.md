# Текущее состояние

Продакшн: **https://thinkred.ru/assistant/** (статика + LLM-прокси на том же origin `/api`,
модель по умолчанию — бесплатная через OpenRouter, ключ на сервере).
Репозиторий: **https://github.com/thethinkred-ai/ml-research-assistant** (CI зелёный;
для автодеплоя нужны secrets `VPS_HOST`/`VPS_SSH_KEY`).

## Что готово

- Полный каркас по методике В. С. Безруковой: актуальность, противоречие, проблема, объект,
  предмет, цель, задачи, гипотеза, методы, этапы, план глав, шаблоны введения и заключения,
  титульный лист, стартовая литература + ссылки на подбор источников.
- **Модель исследовательской логики (v1.3, по рецензии):** реестр утверждений (CLM-…) с
  типизацией (8 типов) и статусами, Source Manager (SRC-…, DOI/URL, надёжность, резолвимость),
  научный линтер (покрытие источниками, отдельные предупреждения на причинные/количественные
  без доказательств), Research completeness по выполненным элементам.
- **Гипотеза-конструктор** «Если X, то Y, потому что M, при условиях A и B»; **новизна —
  чеклист с основанием** (автоутверждение «впервые…» удалено); **исследовательские вопросы**
  до аппарата; **тип исследования** отдельно от формата работы; дисциплинарные профили
  с общим профилем по умолчанию.
- **Режимы LLM:** Explore / Verify / Compare / Critic (таксономия 9 ошибок) / марксистская
  категориальная экспертиза — поверх обычного Write-развёртывания.
- Развёртывание текста без клиентского ключа: ретраи, отмена, дозапуск, параллельность,
  редактируемые секции; черновик переживает правки конструкторов.
- Экспорт: .md, .doc (титульный лист), .html, печать/PDF, копирование, шаринг; в экспорт
  входит реестр утверждений и источников.
- Research-бриф для OpenResearch с разделом реестра (агент ведёт CLM/SRC).
- Прокси с защитой бюджета; 307 проверок в 6 наборах тестов; CI + деплой после зелёного CI;
  статика на thinkred.ru обновляется автоматически (workflow «Site deploy (FTP)»).

## Чего нет (осознанно или в очереди — этапы V1.4/V2.0 рецензии)

- Полного исследовательского графа с версионированием (v0.1→v1.0) — формат реестра уже
  готовит почву; версия исследования пока одна.
- Source resolver с автоматической проверкой существования источника по DOI/Crossref —
  сейчас резолвимость фиксируется вручную (DOI/URL).
- Потоковой генерации (SSE); «настоящего» DOCX; поиска литературы по API; PWA.
- Раунда Writer→Critic→Revision в один клик (Critic уже есть как отдельный режим).

## Известные ограничения

- Качество прозы зависит от подключённой модели; бесплатный апстрим может быть медленным.
- Методологическая рамка (марксизм-ленинизм) задана намеренно и помечается в текстах.
- Прокси логирует IP; ротация логов — на совести эксплуатирующего (см. infrastructure/).
