# Текущее состояние

Продакшн: **https://thinkred.ru/assistant/** (статика + LLM-прокси на том же origin `/api`,
модель по умолчанию — бесплатная через OpenRouter, ключ на сервере).

## Что готово

- Полный каркас по методике В. С. Безруковой: актуальность, противоречие, проблема, объект,
  предмет, цель, задачи, гипотеза, методы, этапы, новизна, значимость, план глав, шаблоны
  введения и заключения, стартовая литература + ссылки на подбор источников.
- Проверка темы (широта/перегруженность), титульный лист, словарь терминов, пресеты дисциплин,
  детерминированная вариативность формулировок.
- Развёртывание через модель без клиентского ключа: ретраи, таймаут, отмена, дозапуск упавших
  секций, параллельность 2, редактируемые секции черновика, предпросмотр.
- Экспорт: .md, Word-совместимый .doc (титульный лист, разрыв страницы), автономный .html,
  печать/PDF, копирование, ссылка-шаринг; автосохранение формы.
- Research-бриф для OpenResearch (alphaXiv) — handoff для исследовательских агентов.
- Прокси с защитой бюджета: rate-limit (мин/час), дневной лимит, whitelist моделей, таймауты, логи.
- 191 проверка в 5 наборах тестов; CI (тесты → линт → gitleaks) и деплой на VPS после зелёного CI.

## Чего нет (осознанно или в очереди)

- Потоковой генерации (SSE) — секции появляются только целиком.
- «Настоящего» DOCX (сейчас — Word-совместимый HTML .doc).
- Поиска реальной литературы по API (сейчас — готовые поисковые ссылки).
- PWA (офлайн-установка).
- Глубокой интеграции с OpenResearch — появится, если у `orx` возникнет HTTP API.

## Известные ограничения

- Качество прозы зависит от подключённой модели; бесплатный апстрим может быть медленным.
- Методологическая рамка (марксизм-ленинизм) задана намеренно и помечается в текстах.
- Прокси логирует IP; ротация логов — на совести эксплуатирующего (см. infrastructure/).
